# CRUD Employee Management System

📊 **Employee Management System** is a simple web app built with React.js for the front-end and JSON Server for the back-end. This app allows users to **create, read, update, and delete (CRUD)** employee data.

## 🚀 Features
- **Create** new employee records
- **Read** employee details
- **Update** employee information
- **Delete** employee records

## 🛠️ Technologies Used
- **Frontend**: React.js
- **Backend**: JSON Server (Mock database)
- **Styling**: Bootstrap for responsive UI

## 🔧 Installation

1. Clone the repo:

   ```bash
   git clone https://github.com/Thejasvini-13/CRUD-Project.git
Navigate to the project directory:

cd CRUD-Project
Install frontend dependencies:

npm install
Run the backend (JSON Server):

To run the backend, make sure you're in the crud-backend folder, and then run:

json-server --watch db.json --port 5001

Start the frontend React app:

npm start
🖥️ Usage
Open your browser and go to http://localhost:3000 to view the frontend.

The backend (JSON Server) will be running on http://localhost:5001.

📝 Notes
This project is intended for learning purposes and uses a mock backend (json-server). The data will be lost when the server restarts.
